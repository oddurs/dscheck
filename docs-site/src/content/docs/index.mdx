<CardGrid stagger>
  <Card title="Knows your tokens" icon="approve-check">
    Reads the token source you already have — Tailwind v4 `@theme`, `:root` custom
    properties — and enforces membership, not just "use a variable".
  </Card>
  <Card title="Built for agent-written UI" icon="rocket">
    Coding agents hallucinate plausible off-system values. In one test, an agent
    produced **19 off-system values** on a component task — and **0** with the
    dscheck hook feeding fixes back.
  </Card>
  <Card title="Rides your existing linters" icon="puzzle">
    Ships as eslint + stylelint plugins over one core. Editor squiggles, `lint-staged`,
    and CI severities come free. The CLI adds baselines, SARIF, and an agent format.
  </Card>
  <Card title="Defaults that never cry wolf" icon="seti:config">
    Exact-match-only autofix, `calc()`/`clamp()` literals skipped, dynamic classnames
    never guessed at, and a pinned real-world corpus gating every release.
  </Card>
</CardGrid>

:::tip[This site eats the cooking]
Every color, size, and shadow on this page comes from a
[56-token design system](https://github.com/oddurs/dscheck/blob/main/docs-site/src/styles/tokens.css)
— and dscheck lints this site's own stylesheets in CI. One raw hex in our CSS and our
build fails.
:::
